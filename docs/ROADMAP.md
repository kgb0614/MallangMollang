## 개발 방향

MORT 수준의 완성도를 목표로 하되, **현재 구현 가능한 범위 안에서 최대한** 만드는 것을 원칙으로 한다.

핵심 가치는 그대로 유지한다:
- OCR 오류를 LLM이 교정해서 번역
- 문맥(이전 번역 히스토리)을 참고해서 자연스러운 번역
- **번역 프로필**: 해당 콘텐츠의 장르/분위기/인물 정보를 미리 주입해서 맥락에 맞는 번역

---

## 현재 동작 가능한 것

- 영역 지정 → Gemini(AI Studio/Vertex) → 오버레이 번역 표시
- 사이드 패널 모드 (오버레이 대안, 번역 히스토리 표시)
- Vision 모드 (설정 → 번역 탭에서 체크박스 활성화)
- 글로벌 단축키, 변경 감지, 번역 캐시, 문맥 기억
- 번역 프로필 (수동 편집 + LLM 자동 생성)
- API 키 Fernet 암호화 저장
- 번역 로그 파일 저장, 진단 정보 복사

---

## Phase 1 — 안정화 ✅ 완료

### 1-1. OCR 신뢰도 필터링 ✅ 완료

`pipeline.py`에서 `confidence < 30.0` 줄을 번역 전에 자동 제외. 필터링 시 로그 출력.

---

### 1-2. API 키 암호화 ✅ 완료

`infra/crypto.py` — Fernet 대칭 암호화. 머신 고유 정보(MAC+사용자명)에서 PBKDF2로 키 유도.
`infra/config.py` — 저장 시 자동 암호화, 로드 시 자동 복호화. 기존 평문 키는 다음 저장 시 자동 마이그레이션.

---

## Phase 2 — 핵심 기능 (현재)

> 상세 구현 스펙: `docs/Phase2-Spec.md` 참조

### 2-1. 번역 프로필 ✅ 완료

구현 완료된 파일:
- `core/profiles.py` — `TranslationProfile` 데이터 + `ProfileManager` (저장/불러오기/LLM 자동 생성)
- `ui/settings.py` — "번역 프로필" 탭 (키워드 자동 생성, 수동 편집, 용어집 테이블, 저장/삭제)
- `core/translator.py` — `set_profile_hint()` + 3개 시스템 프롬프트 빌더에 `【번역 맥락 정보】` 블록 주입
- `main.py` — `ProfileManager` 생성, `_apply_profile()`, 설정 저장 시 재적용

---

### 2-2. 사이드 패널 ✅ 완료

구현 완료된 파일:
- `display/panel.py` — `SidePanel(QWidget)` 번역 히스토리 표시 (QTextBrowser 기반)
- `main.py` — `display.mode == "panel"` 분기, 설정 저장 시 모드 전환
- `ui/settings.py` — 표시 탭에서 오버레이/패널 모드 선택

---

### 2-3. 커서 추적 모드 ❌ 폐기

구현 후 테스트 결과 실용성 부족으로 판단. `git revert`로 롤백 완료.
차후 더 좋은 활용 방법이 떠오르면 재검토.

---

### 2-4. 영속 캐시 ✅ 완료 (P2-1)

`cache.py`에 `save()`/`load()` 추가. `main.py`에서 앱 시작 시 로드, 종료 시 저장.

---

### 2-5. 스냅샷 오버레이 정리 ✅ 완료 (P2-2)

ESC 글로벌 단축키, 스냅샷 모드 클릭 닫기, 자동 타이머 지원.

---

### 2-6. OCR 전처리 미리보기 ✅ 완료 (P2-3)

`ocr.py`에 `preview_preprocess()`, `ui/ocr_preview.py` 신규 미리보기 대화상자.

---

### 2-7. 다중 OCR 영역 ✅ 완료 (P2-4)

`config.py` regions 구조, 기존 region 자동 마이그레이션, 영역별 독립 감지·오버레이.

---

### 2-8. 영역 크기 조정·삭제 UI ✅ 완료 (P2-5)

`ui/region_editor.py` 신규 — 8방향 리사이즈, 드래그 이동, ✕ 삭제.

---

### 2-9. 윈도우 지정 캡처 + OCR 제외 영역 ✅ 완료 (P2-6)

`capture.py`에 `capture_window()`, `mask_exclude_zones()`. 파이프라인에서 자동 적용.

---

### 2-10. 클립보드 자동 복사 ✅ 완료 (P2-7)

설정에서 On/Off. 번역 완료 시 `QApplication.clipboard().setText()` 호출.

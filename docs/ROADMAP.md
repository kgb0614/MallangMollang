# 말랑몰랑 — 개발 로드맵

> 작성일: 2026-06-11 (최종 수정: 2026-06-14)
> 기준 브랜치: main

---

## 개발 방향

MORT 수준의 완성도를 목표로 하되, **현재 구현 가능한 범위 안에서 최대한** 만드는 것을 원칙으로 한다.

핵심 가치는 그대로 유지한다:
- OCR 오류를 LLM이 교정해서 번역
- 문맥(이전 번역 히스토리)을 참고해서 자연스러운 번역
- **번역 프로필**: 해당 콘텐츠의 장르/분위기/인물 정보를 미리 주입해서 맥락에 맞는 번역

---

## 현재 동작 가능한 것

- 영역 지정 → Gemini(AI Studio/Vertex) → 오버레이 번역 표시
- 사이드 패널 모드 (오버레이 대안, 번역 히스토리 표시)
- Vision 모드 (설정 → 번역 탭에서 체크박스 활성화)
- 글로벌 단축키, 변경 감지, 번역 캐시, 문맥 기억
- 번역 프로필 (수동 편집 + LLM 자동 생성)
- API 키 Fernet 암호화 저장
- 번역 로그 파일 저장, 진단 정보 복사
- 다중 OCR 영역 (최대 5개), 영역 편집 핸들 (드래그/리사이즈/삭제)
- 윈도우 지정 캡처 + 윈도우 위치 추적 (300ms 타이머)
- MORT 스타일 오버레이 (QPainterPath 이중 외곽선, 폰트 비례 두께)
- 번역 이력 내보내기 (txt/csv)
- 자동 색상 매핑 (배경 휘도 분석 → 대비 텍스트/외곽선 색상)
- 영속 캐시 (디스크 저장/로드)
- 스냅샷 모드 (1회 번역, 클릭/ESC/타이머로 닫기)
- OCR 전처리 미리보기
- 클립보드 자동 복사

## Phase 1 — 안정화 ✅ 완료

### 1-1. OCR 신뢰도 필터링 ✅ 완료

`pipeline.py`에서 `confidence < 30.0` 줄을 번역 전에 자동 제외. 필터링 시 로그 출력.

---

### 1-2. API 키 암호화 ✅ 완료

`infra/crypto.py` — Fernet 대칭 암호화. 머신 고유 정보(MAC+사용자명)에서 PBKDF2로 키 유도.
`infra/config.py` — 저장 시 자동 암호화, 로드 시 자동 복호화. 기존 평문 키는 다음 저장 시 자동 마이그레이션.

## Phase 2.5 — 오버레이 개선 + 부가기능 ✅ 완료

### 2.5-1. MORT 스타일 오버레이 렌더링 ✅ 완료

- QPainterPath + QPainterPathStroker 기반 이중 외곽선 (outer: `font_size * 0.3`, inner: `font_size * 0.12`)
- 글자 단위 줄바꿈 (`_wrap_text`)
- 누적 y_offset으로 번역 줄 겹침 방지
- 배경 알파값 225 (near-opaque)로 원문 위를 덮어 가독성 확보

---

### 2.5-2. 번역 이력 내보내기 ✅ 완료

- 내용: 번역 시각, 원문, 번역문
- 오버레이 모드에서도 히스토리 누적

---

## Phase 3 — 마무리 기능 ✅ 완료

### 3-1. 사용자 번역 DB ✅ 완료

- `core/user_dict.py` — `UserDictionary` (JSON 영속 저장, 완전/부분 일치 검색)

---

### 3-2. OCR 이미지 전처리 옵션 ✅ 완료

- 설정 > 캡처 탭에 밝기(0.5~2.0)/대비(0.5~3.0)/그레이스케일 조정 추가
- 캡처 후 OCR 전에 Pillow `ImageEnhance`로 처리
- OCR 미리보기에도 동일 전처리 적용
- 설정 경로: `capture.preprocess.brightness`, `capture.preprocess.contrast`, `capture.preprocess.grayscale`

## 폐기/스킵 결정 (사용자 확정)

| 항목 | 결정 | 사유 |
|------|------|------|
| 커서 추적 모드 | ❌ 폐기 | 실용성 부족, 버그 우려 |
| 번역 결과 스트리밍 | ❌ 스킵 | "통짜 번역을 원하지 한줄씩 원하는 경우는 거의 없다" |

| 온보딩 화면 | ⏭ 나중에 | 개인 사용 목적 |
| 스타일 프리셋 저장 UI | ⏭ 나중에 | UI/UX 작업 시 진행 |
| Steam 메타데이터 연동 | ⏭ 나중에 | 번역 프로필 2단계 |
| 배포 패키징 | ⏭ 나중에 | 기능 안정화 후 |
| LLM 추론 파라미터 설정 | ❌ 스킵 | 현재 추론 모델 비활성화 불가 |

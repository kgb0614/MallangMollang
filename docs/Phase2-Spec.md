## 1. 개요

Phase 1(MVP)이 완료되어 기본 번역 파이프라인이 안정적으로 동작하고 있다.
Phase 2에서는 **실사용 편의성**을 높이는 기능을 추가한다.

MORT와의 비교 분석 결과, 기능 수에서는 뒤처지지만
LLM 기반 OCR 교정·문맥 기억·Vision 모드·번역 프로필이라는 핵심 차별점은 유지되고 있다.
Phase 2에서는 이 차별점을 훼손하지 않으면서 MORT가 갖춘 실용적 기능을 선별 도입한다.

### 구현 순서

| 순서 | 기능 ID | 기능명 | 예상 시간 | 난이도 |
|------|---------|--------|-----------|--------|
| 1 | P2-1 | 영속 캐시 (디스크 저장) | 1~2시간 | 하 |
| 2 | P2-2 | 스냅샷 오버레이 정리 | 1시간 | 하 |
| 3 | P2-3 | OCR 전처리 미리보기 | 2~3시간 | 하 |
| 4 | P2-4 | 다중 OCR 영역 | 6~8시간 | 중상 |
| 5 | P2-5 | 영역 크기 조정·삭제 UI | 3~4시간 | 중 |
| 6 | P2-6 | 윈도우 지정 캡처 + OCR 제외 영역 | 4~5시간 | 중 |
| 7 | P2-7 | 클립보드 자동 복사 | 30분 | 하 |

### P2-1. 영속 캐시 (디스크 저장)

**PRD 연결:** F4-1 확장

#### 2-1-1. 목적

현재 번역 캐시는 메모리에만 존재하여 앱 재시작 시 소멸된다.
동일 텍스트를 다시 만나면 API를 재호출해야 하므로 비용이 낭비된다.
캐시를 디스크에 저장하여 앱 재시작 후에도 즉시 캐시 히트가 발생하도록 한다.

#### 2-1-2. 동작 방식

```
앱 시작 → translation_cache.json 로드 → 메모리 LRU 캐시에 적재
         ↕ (기존과 동일하게 캐시 조회/저장)
앱 종료 → 메모리 캐시를 translation_cache.json에 덤프
```

- **저장 시점:** 앱 정상 종료 시 (`closeEvent` 또는 `atexit`)
- **저장 경로:** 프로젝트 루트 `translation_cache.json` (config.json과 동일 위치)
- **파일 형식:** JSON — `[["sha256_hash", "번역 결과"], ...]` (OrderedDict의 items)
- **최대 크기:** `config.cache.max_size` (기본 100)와 동일. 로드 시 초과분은 LRU 순서로 잘림

#### 2-1-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|-----------|
| `core/cache.py` | `save(path)`, `load(path)` 메서드 추가 |
| `main.py` | 앱 시작 시 `cache.load()`, 종료 시 `cache.save()` 호출 |

#### 2-1-4. 인터페이스

```python
# core/cache.py 추가 메서드
def save(self, path: Path) -> None:
    """캐시를 JSON 파일로 저장합니다."""

def load(self, path: Path) -> None:
    """JSON 파일에서 캐시를 불러옵니다. 파일이 없으면 무시합니다."""
```

#### 2-1-5. 엣지 케이스

- 파일이 없거나 손상된 경우: 경고 출력 후 빈 캐시로 시작 (앱 종료 시 새로 생성)
- 파일의 항목 수 > max_size: 뒤쪽(최신) 항목만 max_size개 로드
- 앱 비정상 종료 시: 캐시 손실. 주기적 자동 저장은 Phase 2에서는 구현하지 않음
- 캐시 수동 초기화(`clear`) 시: 메모리만 비우고 파일은 다음 종료 시 덮어씌움

### P2-2. 스냅샷 오버레이 정리

**PRD 연결:** F7-1 개선

#### 2-2-1. 목적

스냅샷(1회 번역) 실행 후 오버레이와 영역 표시가 화면에 계속 남아 사용자를 방해한다.
사용자가 결과를 확인한 후 간편하게 정리할 수 있어야 한다.

#### 2-2-2. 동작 방식

세 가지 정리 트리거를 모두 지원한다:

| 트리거 | 동작 |
|--------|------|
| **ESC 키** | 글로벌 단축키로 오버레이 + 영역 표시 숨김 |
| **오버레이 클릭** | 오버레이 영역 아무 곳이나 클릭하면 숨김 (실시간 모드에서는 클릭 투과 유지) |
| **자동 타이머** | 설정 가능한 시간(기본 0=비활성) 후 자동 페이드아웃 |

- 실시간 모드에서는 ESC 키만 동작 (클릭 투과·타이머 비적용)
- 스냅샷 모드에서만 클릭 해제와 타이머가 활성화됨

#### 2-2-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|-----------|
| `display/overlay.py` | 스냅샷 모드 플래그 추가. 스냅샷일 때 클릭 투과 해제 + 클릭 시 숨김 |
| `infra/hotkeys.py` | `dismiss_requested` 시그널 추가 (ESC 키) |
| `main.py` | ESC 시그널 → 오버레이+영역표시 숨김 연결 |
| `infra/config.py` | `display.snapshot_auto_dismiss_ms` 설정 키 추가 (기본 0) |

#### 2-2-4. 엣지 케이스

- 스냅샷 후 곧바로 실시간 모드 시작 시: 오버레이가 실시간 모드로 전환되며 클릭 투과 복원
- ESC 키가 다른 단축키와 충돌할 경우: ESC는 하드코딩하지 않고 설정 가능하게 구현

### P2-3. OCR 전처리 미리보기

**PRD 연결:** F3-3 확장

#### 2-3-1. 목적

현재 Tesseract가 보는 이진화 이미지를 사용자가 볼 수 없다.
OCR 오인식 문제 발생 시 원인 파악이 어렵다.
전처리 결과를 별도 창에 표시하여 설정 튜닝을 돕는다.

#### 2-3-2. 동작 방식

```
사용자 조작:
  트레이 메뉴 → "OCR 미리보기" 또는 단축키
  → 별도 Qt 창에 3장의 이미지를 나란히 표시:
     [원본 캡처] [전처리 결과 (이진화)] [OCR 바운딩 박스]
```

- 미리보기 창은 번역 루프와 독립적으로 동작 (1회 스냅샷)
- 이미지 위에 OCR 감지된 단어들의 바운딩 박스를 색상으로 표시
- 신뢰도 < 30인 단어는 빨간 박스, 나머지는 초록 박스
- 창 하단에 OCR 텍스트 출력 (복사 가능)

#### 2-3-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|-----------|
| `core/ocr.py` | `preview_preprocess(image)` 메서드 추가 — 원본·전처리·박스 이미지 3장 반환 |
| `ui/ocr_preview.py` | **신규** — 미리보기 창 (`QDialog`) |
| `ui/tray.py` | "OCR 미리보기" 메뉴 항목 추가 |
| `main.py` | 메뉴 시그널 → 미리보기 창 연결 |

#### 2-3-4. 인터페이스

```python

def preview_preprocess(self, image: Image) -> tuple[Image, Image, Image, str]:

    번역 파이프라인과 독립적으로 호출됩니다.
```

### P2-4. 다중 OCR 영역

**PRD 연결:** F1-1 확장 (기존 "복수 영역 지정" 요구사항 구현)

#### 2-4-1. 목적

현재 1개 영역만 지정 가능하여, 게임에서 대사창과 시스템 메시지를
동시에 번역할 수 없다. 여러 영역을 독립적으로 관리한다.

#### 2-4-2. 동작 방식

```
사용자가 영역 추가:
  Ctrl+Shift+R → 새 영역 드래그 → 기존 영역에 추가 (교체가 아님)

각 영역은 독립 파이프라인:
  Region A: 캡처A → 감지A → OCR/번역A → 오버레이A
  Region B: 캡처B → 감지B → OCR/번역B → 오버레이B

변경 감지도 독립적:
  A영역 화면이 바뀌면 A만 재번역, B는 그대로 유지
```

#### 2-4-3. 설정 구조 변경

```python
# 기존 (단일 영역)
"capture": {
    "region": [x, y, w, h],  # 또는 None
}

# 변경 후 (다중 영역)
"capture": {
    "regions": [
        {"id": 1, "name": "대사창", "rect": [100, 500, 800, 200], "enabled": True},
        {"id": 2, "name": "시스템", "rect": [50, 50, 300, 100], "enabled": True},
    ],
    # "region" 키는 하위호환용으로 유지 — 로드 시 regions[0]로 마이그레이션
}
```

- `id`: 영역 고유 식별자 (자동 증가)
- `name`: 사용자가 지정하는 이름 (기본: "영역 1", "영역 2", ...)
- `rect`: [x, y, width, height]
- `enabled`: 활성/비활성 토글

#### 2-4-4. 수정 대상 파일

| 파일 | 수정 내용 | 작업량 |
|------|-----------|--------|
| `infra/config.py` | `DEFAULT_CONFIG.capture.regions` 추가, 기존 `region` → `regions` 마이그레이션 | 소 |
| `core/capture.py` | `capture_region(rect)` — rect 파라미터를 받도록 수정 | 소 |
| `core/detector.py` | 영역별 독립 해시 저장 (dict: `{region_id: prev_hash}`) | 소 |
| `core/cache.py` | 변경 없음 — 텍스트 해시 기반이므로 영역과 무관 | 없음 |
| `core/pipeline.py` | `run_once(region)` — 특정 영역에 대해 실행. `run_loop(regions)` — 모든 영역 순회 | 중 |
| `display/overlay.py` | 영역별 독립 오버레이 렌더링. 기존 단일 페인트를 영역별 딕셔너리로 관리 | 중 |
| `display/area_indicator.py` | 복수 영역 표시. 각 영역별 `QWidget` 생성 | 중 |
| `ui/region_selector.py` | "추가" 모드 지원 — 새 영역이 기존 영역을 대체하지 않고 추가 | 소 |
| `main.py` | 영역 관리 로직 전면 수정 — 추가/삭제/활성화 | 중 |

#### 2-4-5. 파이프라인 순회 방식

```python
# pipeline.py — run_loop() 변경 개념
async def run_loop(self, regions: list[dict]):
    while self._running:
        for region in regions:
            if not region["enabled"]:
                continue
            region_id = region["id"]
            image = self._capture.capture_region(region["rect"])
            if not self._detector.has_changed(image, region_id):
                continue
            # OCR → 캐시 → 번역 → 콜백(region_id 포함)
        await asyncio.sleep(interval / 1000)
```

- 영역을 **순차 처리** (병렬 아님) — API 호출이 병목이므로 병렬화 이점 적음
- 변경된 영역만 번역하므로 실질적 API 호출 횟수는 단일 영역과 비슷

#### 2-4-6. 하위호환

기존 `config.json`에 `capture.region`만 있는 경우:
1. `Config._load()` 시 `region` → `regions[0]`으로 자동 변환
2. 변환 후 `region` 키 유지 (이전 버전 호환)
3. 저장 시 `regions`만 기록

#### 2-4-7. 영역 개수 제한

- 최대 5개 (하드코딩). 초과 시 토스트 경고
- 사유: 영역이 많으면 API 호출 빈도 증가 + 오버레이 복잡도 증가

### P2-5. 영역 크기 조정·삭제 UI

**PRD 연결:** F1-1 확장

#### 2-5-1. 목적

지정된 OCR 영역을 삭제하거나 크기/위치를 수정하려면
현재는 영역을 처음부터 다시 지정해야 한다.
일반 윈도우처럼 드래그로 크기 조정하고 개별 닫기가 가능해야 한다.

#### 2-5-2. 동작 방식

**"영역 편집 모드"와 "번역 모드"를 분리한다.**

```
번역 모드 (기본):
  → 영역은 얇은 테두리로만 표시 (기존 area_indicator)
  → 클릭 투과, 조작 불가

영역 편집 모드 (트레이 메뉴 또는 단축키로 진입):
  → 모든 영역이 반투명 핸들 + 테두리로 표시
  → 영역 내부 드래그 → 위치 이동
  → 모서리/가장자리 드래그 → 크기 조정
  → 우상단 ✕ 버튼 → 해당 영역 삭제 (확인 없이 즉시)
  → 영역 이름 표시 (좌상단에 작은 레이블)
  → ESC 또는 "편집 완료" 버튼 → 번역 모드로 복귀
```

#### 2-5-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|-----------|
| `ui/region_editor.py` | **신규** — `RegionHandle(QWidget)` 리사이즈·이동·삭제 지원 |
| `display/area_indicator.py` | 편집 모드 진입 시 `RegionHandle`로 전환 |
| `ui/tray.py` | "영역 편집" 메뉴 항목 추가 |
| `main.py` | 편집 모드 상태 관리, 편집 완료 시 config 저장 |

#### 2-5-4. RegionHandle 위젯 스펙

```
┌──[대사창]──────────────── ✕ ┐
│                              │  ← 반투명 배경 (rgba 0,100,200,40)
│                              │
│                              │
│         (드래그=이동)        │
│                              │
│                              │
└──────────────────────────────┘
 ↑ 모서리/가장자리에 리사이즈 핸들 (8방향)
```

- **이름 레이블**: 좌상단, 작은 폰트, 반투명 배경
- **삭제 버튼**: 우상단 ✕, 호버 시 빨간색
- **리사이즈**: 마우스 커서가 가장자리 5px 이내에 오면 리사이즈 커서 변경
- **최소 크기**: 50×50px

### P2-6. 윈도우 지정 캡처 + OCR 제외 영역

**PRD 연결:** F1-1 확장

#### 2-6-1. 윈도우 지정 캡처

**목적:**
현재는 화면 좌표 기반으로 캡처하므로, 대상 창을 이동하면 영역이 어긋난다.
특정 윈도우를 지정하면 창이 이동/리사이즈되어도 자동으로 따라간다.

**동작 방식:**
```
설정 → 캡처 탭 → "캡처 대상" 드롭다운:
  ● 화면 좌표 (기존)
  ● 윈도우 지정 → [윈도우 선택] 버튼

윈도우 선택:
  버튼 클릭 → 마우스가 십자 커서로 변경
  → 원하는 창 클릭 → 해당 창의 핸들(hwnd) + 타이틀 저장
  → 이후 캡처 시 hwnd의 현재 위치를 매번 조회

영역 좌표는 윈도우 기준 상대 좌표로 저장:
  config: {"window_hwnd_title": "게임 이름", "rect": [상대x, 상대y, w, h]}
  캡처 시: win32gui.GetWindowRect(hwnd) + 상대좌표 → 절대좌표 계산
```

**수정 대상 파일:**

| 파일 | 수정 내용 |
|------|-----------|
| `core/capture.py` | `capture_window(hwnd, relative_rect)` 메서드 추가 |
| `infra/config.py` | `capture.target_mode` ("screen" \| "window"), `capture.window_title` 설정 추가 |
| `ui/settings.py` | 캡처 탭에 모드 드롭다운 + 윈도우 선택 UI |
| `main.py` | 캡처 호출 시 모드에 따라 분기 |

**의존성:** `pywin32` 패키지 추가 (Windows 전용 — 이미 Windows 전용 앱)

**엣지 케이스:**
- 대상 창이 닫힌 경우: 토스트 경고 + 번역 일시 정지
- 대상 창이 최소화된 경우: 캡처 스킵 (변경 감지와 동일하게 처리)
- 전체화면 게임: `GetWindowRect`로 좌표 획득 가능하나, mss 캡처가 정상 동작하지 않을 수 있음. 이 경우 "전체화면 미지원" 토스트 표시

#### 2-6-2. OCR 제외 영역

**목적:**
HP 바, 미니맵, UI 아이콘 등 텍스트가 아닌 영역이 OCR에 잡히면
불필요한 노이즈가 번역 품질을 떨어뜨린다. 특정 서브 영역을 제외한다.

**동작 방식:**
```
영역 편집 모드에서:
  우클릭 → "제외 영역 추가" → 빨간 반투명 영역 드래그
  → 해당 영역은 캡처 후 검은색으로 마스킹 → Tesseract가 무시

기술적으로:
  캡처 이미지 → PIL ImageDraw로 제외 영역을 (0,0,0)으로 칠함 → OCR 전달
```

**설정 구조:**
```python
"capture": {
    "regions": [
        {
            "id": 1,
            "rect": [100, 500, 800, 200],
            "exclude_zones": [
                [0, 0, 50, 50],    # 영역 내 상대좌표 [rx, ry, rw, rh]
                [700, 150, 100, 50]
            ]
        }
    ]
}
```

**수정 대상 파일:**

| 파일 | 수정 내용 |
|------|-----------|
| `core/capture.py` | 캡처 후 제외 영역 마스킹 처리 |
| `ui/region_editor.py` | 제외 영역 추가/삭제 UI (빨간 반투명 박스) |
| `infra/config.py` | `exclude_zones` 설정 구조 추가 |

### P2-7. 클립보드 자동 복사

**PRD 연결:** 신규 기능

#### 2-7-1. 목적

번역 결과를 메모장이나 채팅 등 다른 앱에 바로 붙여넣기하고 싶을 때,
수동으로 텍스트를 선택·복사하는 불편을 줄인다.

#### 2-7-2. 동작 방식

```
설정 → 번역 탭 → ☑ 번역 결과 클립보드 자동 복사

활성화 시:
  번역 완료 → 결과 텍스트가 자동으로 시스템 클립보드에 복사
  → 사용자가 다른 앱에서 Ctrl+V로 붙여넣기 가능
```

#### 2-7-3. 수정 대상 파일

| 파일 | 수정 내용 |
|------|-----------|
| `infra/config.py` | `translation.auto_clipboard` 설정 키 추가 (기본 `false`) |
| `ui/settings.py` | 번역 탭에 체크박스 추가 |
| `main.py` | 번역 완료 콜백에서 `QApplication.clipboard().setText(result)` 호출 |

#### 2-7-4. 주의사항

- 기본값은 **비활성** — 기존 클립보드 내용을 덮어쓰므로 명시적 동의 필요
- 실시간 모드에서 매 번역마다 클립보드가 갱신되므로, 빈번한 갱신이 불편할 수 있음
  → 실시간 모드에서는 "변경된 경우에만" 복사 (변경 감지 통과한 경우만)

### 3-4. 충돌 가능성 분석

| 기능 조합 | 충돌 위험 | 대응 |
|-----------|-----------|------|
| 다중 영역 + 사이드 패널 | 낮음 | 패널은 모든 영역의 번역을 시간순으로 표시 |
| 다중 영역 + 오버레이 | 중간 | 영역별 독립 렌더링 필요. 오버레이 paintEvent 구조 변경 |
| 윈도우 캡처 + 다중 영역 | 낮음 | 영역 좌표가 윈도우 기준 상대좌표이므로 자연스럽게 호환 |
| 영속 캐시 + 다중 영역 | 없음 | 캐시는 텍스트 해시 기반이므로 영역과 무관 |
| 스냅샷 정리 + 다중 영역 | 낮음 | ESC로 모든 영역의 오버레이를 동시에 정리 |
| 클립보드 + 다중 영역 | 중간 | 여러 영역이 동시에 번역되면 마지막 번역만 클립보드에 남음 → 사용자에게 이 동작을 설정 툴팁으로 안내 |

## 4. 테스트 체크리스트

### P2-1. 영속 캐시

- [ ] 앱 시작 → 번역 → 앱 종료 → `translation_cache.json` 생성 확인
- [ ] 앱 재시작 → 동일 텍스트 → 캐시 히트 (API 미호출) 확인
- [ ] `translation_cache.json` 삭제 후 → 앱 정상 시작 확인
- [ ] 캐시 수동 초기화 후 → 재시작 시 빈 캐시 확인

### P2-2. 스냅샷 정리

- [ ] 스냅샷 후 ESC → 오버레이 + 영역 표시 숨김 확인
- [ ] 스냅샷 후 오버레이 클릭 → 숨김 확인
- [ ] 실시간 모드에서 ESC → 오버레이 숨김 확인
- [ ] 실시간 모드에서 클릭 → 투과 유지 (숨기지 않음) 확인

### P2-3. OCR 미리보기

- [ ] 트레이 메뉴 → "OCR 미리보기" → 3장 이미지 표시 확인
- [ ] 바운딩 박스 색상: 신뢰도 30+ 초록, 30 미만 빨강
- [ ] OCR 텍스트 복사 가능 확인

### P2-4. 다중 OCR 영역

- [ ] 영역 추가 → 기존 영역 유지 + 새 영역 추가
- [ ] A영역만 변경 → A만 재번역, B 유지
- [ ] 영역 5개 초과 시 토스트 경고
- [ ] 앱 재시작 후 모든 영역 복원

### P2-5. 영역 편집

- [ ] 편집 모드 진입 → 핸들 표시 + 클릭 투과 해제
- [ ] 모서리 드래그 → 크기 조정 + 최소 50×50px 제한
- [ ] 내부 드래그 → 위치 이동
- [ ] ✕ 버튼 → 영역 삭제
- [ ] ESC → 편집 모드 종료 + 설정 저장

### P2-6. 윈도우 캡처 + 제외 영역

- [ ] 윈도우 선택 → 창 이동 후에도 올바른 위치 캡처
- [ ] 대상 창 닫힘 → 토스트 경고 + 번역 일시 정지
- [ ] 제외 영역 추가 → 해당 부분 OCR에서 무시
- [ ] 제외 영역 삭제 → OCR 정상 복귀

### P2-7. 클립보드

- [ ] 설정 활성화 → 번역 후 Ctrl+V로 결과 붙여넣기 가능
- [ ] 설정 비활성화 → 클립보드 미변경

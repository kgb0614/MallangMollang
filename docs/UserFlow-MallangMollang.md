# 말랑몰랑 (MallangMollang) — User Flow

**문서 버전:** v1.0
**작성일:** 2026-06-01
**관련 문서:** PRD-MallangMollang.md

---

## 개요

본 문서는 말랑몰랑의 사용자 플로우를 두 가지 관점에서 정의한다.

**Part 1 — 시나리오별 태스크 플로우:** 핵심 사용 시나리오 3가지(게임 번역, 웹/문서 탐색, 프리셋 커스터마이징)에 대해 사용자의 행동과 시스템의 처리를 순서대로 기술하며, 분기점(decision point)과 최적화 경로(skip path)를 포함한다.

**Part 2 — 전체 인터랙션 플로우:** 프로그램 최초 설치부터 온보딩, 일상 사용, 번역 루프, 설정 변경까지 실제 사용자가 경험하는 전체 여정을 4단계(Phase)로 구성한다.

---

# Part 1 — 시나리오별 태스크 플로우

## 시나리오 1: 게임 번역 (영역 지정 모드)

**트리거:** 번역이 지원되지 않는 외국어 게임을 플레이할 때
**사용 모드:** 영역 지정 모드
**표시 방식:** 오버레이 자막

### 태스크 플로우

```
[프로그램 실행]
    ↓
[초기 설정 확인] — API 키, 모델, 언어 설정 (최초 1회 또는 변경 시)
    ↓
[영역 지정 모드 활성화] — 단축키로 전환
    ↓
[번역 영역 드래그] — 게임 대화창 등 원하는 영역을 마우스로 지정
    ↓
[자동 캡처 시작] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
    ↓                                                  │
[화면 변경됨?]                                          │
    ├── No → 대기 (설정된 주기 후 재캡처) ─ ─ ─ ─ ─ ─ ┘
    ↓ Yes                                               │
[OCR 텍스트 추출]                                       │
    ↓                                                   │
[캐시에 존재?]                                          │
    ├── Yes → 캐시된 번역 사용 ─ → [오버레이 표시] ─ ─ ┘
    ↓ No                                                │
[LLM 번역] — OCR 오류 교정 + 이전 문맥 참조             │
    ↓                                                   │
[번역 결과 캐시 저장]                                    │
    ↓                                                   │
[오버레이 표시] ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

### 주요 분기점

| 분기점 | 조건 | Yes 경로 | No 경로 |
|--------|------|----------|---------|
| **화면 변경됨?** | 이전 캡처와 이미지 해시 비교 | OCR 추출 진행 | 대기 후 재캡처 (API 호출 절감) |
| **캐시에 존재?** | OCR 추출 텍스트의 해시를 캐시에서 조회 | 캐시된 번역 즉시 표시 | LLM 번역 요청 (비용 발생) |

### 핵심 사용자 경험 포인트

- 영역을 한 번 지정하면 이후 번역은 자동으로 진행된다.
- 대화가 바뀌지 않으면 화면이 깜빡이지 않는다.
- 이전 대사의 맥락이 반영되어 자연스러운 번역이 제공된다.

---

## 시나리오 2: 웹/문서 탐색 (커서 추적 모드)

**트리거:** 외국어 웹 페이지나 문서를 탐색할 때
**사용 모드:** 커서 추적 모드
**표시 방식:** 툴팁 (마우스 커서 근처)

### 태스크 플로우

```
[프로그램 실행]
    ↓
[외국어 콘텐츠 열기] — 웹 페이지, 문서, PDF 등
    ↓
[커서 추적 모드 활성화] — 단축키로 전환
    ↓
[마우스를 텍스트 위로 이동] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
    ↓ 커서 주변 영역 자동 캡처                           │
[이전 캡처와 다름?]                                      │
    ├── No → 현재 번역 유지 (커서 이동 대기) ─ ─ ─ ─ ─ ┘
    ↓ Yes                                                │
[OCR 텍스트 추출]                                        │
    ↓                                                    │
[캐시에 존재?]                                           │
    ├── Yes → 캐시된 번역 사용 ─ → [툴팁 표시] ─ ─ ─ ─ ┘
    ↓ No                                                 │
[LLM 번역] — OCR 오류 교정 + 이전 문맥 참조              │
    ↓                                                    │
[번역 결과 캐시 저장]                                     │
    ↓                                                    │
[툴팁으로 번역 표시] ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

### 시나리오 1과의 차이점

| 항목 | 시나리오 1 (게임) | 시나리오 2 (웹/문서) |
|------|------------------|---------------------|
| **캡처 트리거** | 설정 주기마다 자동 | 마우스 커서 이동 시 |
| **캡처 영역** | 사용자가 미리 지정한 고정 영역 | 커서 주변 자동 감지 영역 |
| **표시 방식** | 오버레이 (고정 위치) | 툴팁 (커서 근처, 유동적) |
| **적합한 콘텐츠** | 대화창이 고정된 게임 | 텍스트가 분산된 웹/문서 |

### 핵심 사용자 경험 포인트

- 읽고 싶은 부분에 마우스를 올리기만 하면 번역이 표시된다.
- 페이지 레이아웃을 변경하지 않으므로 원본 구조가 유지된다.
- 전체 페이지가 아닌 원하는 부분만 선택적으로 번역할 수 있다.

---

## 시나리오 3: 프리셋 커스터마이징

**트리거:** 오버레이 스타일이 현재 환경(어두운 게임, 밝은 문서 등)에 맞지 않을 때
**사용 모드:** 설정 UI
**결과물:** 저장된 스타일 프리셋

### 태스크 플로우

```
[트레이 아이콘 클릭 → 설정 창 열기]
    ↓
[표시 설정 탭 선택]
    ↓
[오버레이 스타일 조정] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
    │  • 폰트 종류                                  │
    │  • 폰트 크기                                  │
    │  • 글자 색상                                  │
    │  • 배경 색상 및 투명도                         │
    │  • 외곽선 유무 및 색상                         │
    ↓                                               │
[미리보기 확인]                                      │
    ↓                                               │
[마음에 듦?]                                         │
    ├── No → 스타일 재조정 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
    ↓ Yes
[프리셋 이름 입력] — 예: "다크게임용", "문서용"
    ↓
[프리셋 저장 완료]
```

### 프리셋 활용 플로우 (저장 이후)

```
[번역 사용 중 스타일 변경 필요]
    ↓
[설정 → 프리셋 목록 열기]
    ↓
[저장된 프리셋 선택] — "다크게임용"
    ↓
[즉시 적용]
```

### 핵심 사용자 경험 포인트

- 한 번 만든 프리셋은 이름으로 저장되어 언제든 불러올 수 있다.
- 게임/문서/웹 등 환경별로 최적화된 프리셋을 미리 만들어 둘 수 있다.
- 미리보기를 통해 실제 적용 전에 결과를 확인할 수 있다.

## 공통 플로우: 표시 모드 전환

세 시나리오 모두에서, 번역 표시 중 단축키를 통해 오버레이 ↔ 사이드 패널을 즉시 전환할 수 있다.

```
[번역 표시 중 (오버레이 or 사이드 패널)]
    ↓
[전환 단축키 입력]
    ↓
[현재 모드 확인]
    ├── 오버레이 → 사이드 패널로 전환
    └── 사이드 패널 → 오버레이로 전환
```

# Part 2 — 전체 인터랙션 플로우

프로그램 설치부터 일상 사용까지, 실제 사용자가 경험하는 전체 여정을 4개 Phase로 구성한다.

---

## Phase 1: 최초 실행 및 온보딩

앱을 처음 설치하고 실행하는 사용자의 여정이다.

```
[프로그램 설치 및 실행]
    ↓
[온보딩 화면 표시] — 주요 기능 및 단축키 안내
    ↓
[LLM 프로바이더 설정]
    │  • API 키 입력 (BYOK) 또는 Ollama 로컬 연결
    ↓
[연결 테스트]
    ├── 실패 → 오류 메시지 + 재입력 안내 → [LLM 프로바이더 설정]
    ↓ 성공
[언어 설정] — 원문 언어 (자동 감지/영/일/중), 대상 언어 (한국어)
    ↓
[온보딩 완료 → 시스템 트레이에 상주]
```

### 핵심 포인트

- 최초 1회만 거치는 과정이며, 이후 실행 시에는 바로 트레이에 상주한다.
- API 키 연결 테스트를 통해 설정 오류를 온보딩 단계에서 조기에 차단한다.
- 모든 설정은 로컬에 저장되어 재실행 시 자동으로 불러온다.

---

## Phase 2: 일상 사용 진입

이미 설정이 완료된 사용자가 번역이 필요할 때의 진입 경로이다.

```
[번역 대상 콘텐츠 열기] — 게임 실행, 웹 페이지, 문서 등
    ↓
[번역 모드 선택 (단축키)]
    ├── 고정 영역 (게임 대화창 등) → [영역 지정 모드 활성화]
    │                                     ↓
    │                               [화면에서 영역 드래그]
    │                                     ↓
    │                               [자동 캡처 루프 시작] → Phase 3으로
    │
    └── 분산된 텍스트 (웹, 문서) → [커서 추적 모드 활성화]
                                       ↓
                                 [마우스 이동 시 자동 캡처] → Phase 3으로
```

### 핵심 포인트

- 단축키 하나로 모드를 선택하고 즉시 번역을 시작할 수 있다.
- 영역 지정 모드는 영역을 한 번 드래그한 뒤 자동으로 전환된다.
- 커서 추적 모드는 별도 영역 지정 없이 마우스 이동만으로 동작한다.

---

## Phase 3: 번역 루프 (핵심 파이프라인)

Phase 2에서 모드가 활성화된 이후, 백그라운드에서 자동으로 반복되는 핵심 처리 흐름이다. 사용자는 이 과정을 직접 조작하지 않으며, 번역 결과만 화면에서 확인한다.

```
[화면 캡처] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
    ↓                                                      │
[변경 감지 — 이미지 해시 비교]                              │
    ├── 변경 없음 → 현재 번역 유지, 다음 캡처 대기 ─ ─ ─ ┘
    ↓ 변경 있음                                            │
[OCR 텍스트 추출] — 이미지 전처리 후 Tesseract 실행        │
    ↓                                                      │
[번역 캐시 조회]                                            │
    ├── 캐시 히트 → 캐시된 번역 즉시 표시 ─ ─ ─ ─ ─ ─ ─ ┘
    ↓ 캐시 미스                                            │
[LLM 번역 요청]                                            │
    │  • OCR 원문 전달                                     │
    │  • 이전 3~5회 번역 문맥 포함                         │
    │  • LLM이 오타 교정 + 자연스러운 번역 수행             │
    ↓                                                      │
[번역 결과 캐시 저장]                                       │
    ↓                                                      │
[화면에 번역 표시]                                          │
    │  • 오버레이: 원문 위에 반투명 자막                    │
    │  • 사이드 패널: 화면 한쪽에 독립 패널                 │
    └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

### 최적화 지점 요약

| 지점 | 조건 | 효과 |
|------|------|------|
| **변경 감지** | 이전 캡처와 동일 | OCR + LLM 호출 전체 스킵 |
| **번역 캐시** | 동일 텍스트 재등장 | LLM 호출 스킵 (즉시 표시) |
| **문맥 기억** | 이전 번역 히스토리 존재 | 번역 품질 향상 (추가 비용 없음) |

### 에러 처리

| 에러 상황 | 사용자에게 보이는 것 |
|-----------|---------------------|
| OCR 추출 실패 (텍스트 없음) | "텍스트를 인식하지 못했습니다" 메시지 표시, 다음 캡처 대기 |
| LLM API 타임아웃 | "번역 응답 대기 중..." 표시 후 재시도, 3회 실패 시 알림 |
| API 키 만료/무효 | 트레이 알림 + 설정 창 자동 열기 |
| 네트워크 끊김 | "네트워크 연결을 확인해주세요" 알림, 연결 복구 시 자동 재개 |

---

## Phase 4: 설정 및 커스터마이징

번역 사용 중 또는 사용 전후에 언제든 접근 가능한 설정 흐름이다. 설정 창을 열어도 번역 루프는 백그라운드에서 계속 동작한다.

```
[트레이 아이콘 클릭 → 설정 창 열기]
    ↓
[설정 탭 선택]
    ├── 프로바이더 → API 키 변경, 모델 전환, 로컬↔클라우드 전환
    ├── 언어 → 원문/대상 언어 변경
    ├── 캡처 → 캡처 주기, 변경 감지 민감도 조절
    ├── 표시 → 오버레이 스타일 조정 + 프리셋 저장/불러오기
    ├── 단축키 → 각 기능별 글로벌 단축키 커스터마이징
    └── 번역 → 문맥 기억 길이, 커스텀 프롬프트, 캐시 관리
```

### 런타임 중 가능한 조작 (단축키)

| 단축키 기능 | 설명 |
|-------------|------|
| **번역 시작/중지** | 번역 루프 일시정지 및 재개 |
| **모드 전환** | 영역 지정 ↔ 커서 추적 모드 전환 |
| **표시 전환** | 오버레이 ↔ 사이드 패널 전환 |
| **영역 재지정** | 현재 영역을 해제하고 새 영역 드래그 |

### 프로그램 종료

```
[트레이 아이콘 → 종료 선택]
    ↓
[현재 설정 자동 저장] — JSON/TOML 파일
    ↓
[프로그램 종료]
```

다음 실행 시 저장된 설정을 자동으로 불러오며, 온보딩 과정 없이 바로 트레이에 상주한다.

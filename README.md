# 말랑몰랑 (MallangMollang)

AI 하이브리드 화면 번역 유틸리티 — Windows PC

## 뭐하는 프로그램?

화면의 텍스트를 OCR로 읽고, LLM이 오타를 교정하면서 자연스럽게 번역해주는 프로그램입니다.

## 기존 도구(MORT)와 뭐가 다른데?

| 차별점 | 설명 |
|--------|------|
| OCR 오류 교정 | OCR이 글자를 잘못 읽어도 LLM이 문맥으로 교정 |
| 문맥 기억 | 이전 대사를 기억해서 스토리가 이어지는 번역 |
| Vision API | OCR 없이 이미지를 LLM에 직접 전달해서 번역 |
| 번역 프로필 | 콘텐츠별 장르/분위기/용어를 사전 정의하여 맞춤 번역 |
| 사용자 사전 | 자주 쓰는 용어를 등록하면 LLM 호출 없이 즉시 치환 |

## 주요 기능

- **실시간 번역** — 지정 영역을 주기적으로 캡처 → OCR → LLM 번역 → 오버레이 표시
- **스냅샷 번역** — 1회성 번역 (클릭/ESC/타이머로 닫기)
- **다중 영역** — 최대 5개 영역을 독립적으로 캡처·번역
- **윈도우 지정 캡처** — 특정 윈도우를 선택하면 영역이 창을 따라 이동
- **MORT 스타일 오버레이** — 이중 외곽선 텍스트, 자동 색상 매핑
- **사이드 패널** — 번역 히스토리 표시 + txt/csv 내보내기
- **번역 프로필** — 콘텐츠명/장르/분위기/용어집 설정 (LLM 자동 생성 지원)
- **사용자 번역 사전** — 완전 일치 시 LLM 스킵, 부분 일치 시 용어 강제
- **OCR 전처리** — 밝기/대비/그레이스케일 조정 + 미리보기
- **클립보드 자동 복사** — 번역 결과를 클립보드에 자동 복사
- **API 키 암호화** — Fernet 암호화로 안전하게 저장
- **컨트롤 패널** — 플로팅 미니 패널로 빠르게 조작 (빠른 설정 포함)

## 설치 방법

### 사전 요구사항

1. **Python 3.11 이상** — https://python.org/downloads
2. **Tesseract OCR** — https://github.com/UB-Mannheim/tesseract/wiki
   - 설치 후 PATH에 추가되어 있어야 합니다
   - 영어 외 언어(일본어, 중국어 등) 필요 시 설치 시 해당 언어 데이터 선택
3. **Google Gemini API 키** — https://aistudio.google.com/apikey

### 패키지 설치

```bash
# 저장소 클론
git clone https://github.com/kgb0614/mallangmollang.git
cd mallangmollang

# 의존성 설치
pip install -r requirements.txt
```

### 실행

```bash
python -m mallangmollang
```

또는

```bash
python mallangmollang/main.py
```

## 처음 실행 시

1. 프로그램이 시작되면 시스템 트레이에 아이콘이, 화면에 컨트롤 패널이 나타납니다
2. 설정 창이 자동으로 열립니다
3. **프로바이더 탭**에서 Gemini API 키를 입력하고 "연결 테스트"로 확인합니다
4. **언어 탭**에서 원문 언어와 OCR 언어를 설정합니다
5. 저장 후 컨트롤 패널에서 **⊕ 영역** 버튼을 눌러 번역할 영역을 드래그합니다
6. 컨트롤 패널에서 **▶ 시작**을 누르면 번역이 시작됩니다

## 컨트롤 패널

화면에 떠 있는 미니 패널로, 트레이 메뉴를 대체하는 빠른 조작 수단입니다.

| 버튼 | 설명 |
|------|------|
| ▶ 시작 / ⏹ 중지 | 실시간 번역 시작/중지 (스냅샷 모드에서는 📷 번역) |
| ⊕ 영역 | 캡처 영역 추가 |
| ⚙ 설정 | 설정 창 열기 |
| ▼ 더보기 | 빠른 설정 펼치기 (모드/표시/클립보드/OCR 미리보기) |

## 트레이 메뉴

트레이 아이콘 우클릭 시:

| 항목 | 설명 |
|------|------|
| 번역 시작 / 번역 중지 | 번역 루프 켜기/끄기 |
| 영역 추가 | 캡처할 화면 영역 추가 |
| 컨트롤 패널 표시 | 컨트롤 패널 다시 열기 |
| OCR 미리보기 | OCR 전처리 결과 확인 |
| 진단 정보 복사 | 디버그 정보 클립보드에 복사 |
| 설정 | 설정 창 열기 |
| 종료 | 프로그램 종료 |

## 설정 항목

| 탭 | 주요 설정 |
|----|-----------|
| 프로바이더 | API 키, 모델, AI Studio / Vertex AI 선택 |
| 언어 | 원문 언어(자동/영/일/중), 번역 언어, OCR 언어 |
| 캡처 | 캡처 주기(ms), 변경 감지 민감도, 윈도우 선택, OCR 전처리(밝기/대비/그레이스케일) |
| 번역 | 문맥 기억 수, Vision API 모드, 캐시 크기 |
| 표시 | 오버레이 스타일 프리셋, 표시 모드(오버레이/사이드 패널), 자동 색상 |
| 번역 프로필 | 콘텐츠별 번역 톤/용어/분위기 설정 (LLM 자동 생성 지원) |
| 사용자 사전 | 원문→번역 용어 등록/삭제 |
| 단축키 | 글로벌 단축키 커스터마이징 |

## 상태

Phase 1~3 기능 구현 + UI/UX 폴리시 완료

- Phase 1 (MVP): 영역 지정 번역, 오버레이, 변경 감지, 캐시, 문맥 기억, API 키 암호화

- Phase 2.5: MORT 스타일 오버레이, 번역 이력 내보내기, 자동 색상 매핑
- Phase 3: 사용자 번역 사전, OCR 이미지 전처리 옵션
- UI/UX: 컨트롤 패널 빠른 설정, 설정 창 다크 테마 통일
